# 06 — Web Server HTTPS

## Servidor

- Sistema operativo: Debian
- IP: `10.21.75.130/28`
- Servicio web: Apache
- Protocolo: HTTPS

El servidor está conectado detrás de FortiGate-B dentro de `10.21.75.128/28`.

## Rol en la práctica

El servidor representa el recurso remoto que debe ser alcanzable por el usuario del Sitio A únicamente a través de la conectividad permitida entre las dos redes mediante el túnel VPN.
