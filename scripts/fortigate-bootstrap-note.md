# Bootstrap CLI — nota de alcance

La práctica exige que la configuración funcional y la demostración de los FortiGate se realicen por GUI.

La CLI se utilizó solamente para la inicialización básica de interfaces/acceso necesaria para poder administrar el appliance por su interfaz web. No se documentan aquí comandos de VPN/policies como si hubieran sido ejecutados por CLI, porque ese transcript exacto no fue conservado.
